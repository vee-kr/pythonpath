Input & Output

Learn how to get information from the user and display results with Python.

What is input and output?

Programs often need to communicate with the user. They can receive information from the user and display information back to them.

Input is information that a program receives from the user.

Output is information that a program displays to the user.

In Python, we can use input() to get information from the user and print() to display information.

Getting input from the user

The input() function allows your program to ask the user for information.

For example, you can ask the user for their name: 

name = input("What is your name? ")
print(name)

When the program runs, Python waits for the user to type something and press Enter.

The information entered by the user is stored in the name variable.

Combining input with text

You can use the information from input() together with other text. 

name = input("What is your name? ")
print("Hello,", name)

If the user enters Alex, the program displays: 

Hello, Alex

You can also ask for other information and store it in different variables. 

name = input("What is your name? ")
hobby = input("What is your hobby? ")

print("Your name is", name)
print("Your hobby is", hobby)
